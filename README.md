
# Credit Score & Loan Approval AI

An end-to-end Machine Learning platform for credit risk
prediction, loan default probability, model explainability
and AI fairness assessment.

## Machine Learning Models
- XGBoost
- CatBoost

## Key Capabilities
- Credit default probability prediction
- Credit risk classification
- Model performance comparison
- SHAP explainability
- Bias and fairness assessment
- Model monitoring
- Interactive Streamlit dashboard
- AI Governance documentation

## Technology Stack
- Python
- Pandas
- NumPy
- XGBoost
- CatBoost
- SHAP
- Streamlit
- Matplotlib
- Pytest

## Dataset
UCI German Credit Dataset

## Project Objective
Build an explainable and fairness-aware credit risk
prediction platform for financial institutions.
